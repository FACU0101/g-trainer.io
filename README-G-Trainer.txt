G-TRAINER — VERSION CORREGIDA

Archivos:
- index.html: estructura de la aplicación.
- styles.css: apariencia visual.
- app.js: lógica y almacenamiento local.

Cómo usar:
1. Extraé todos los archivos en una misma carpeta.
2. Abrí index.html en Chrome o Edge.
3. Para conservar datos, no borres los datos del sitio ni la base IndexedDB GTrainerDB.
4. Antes de probar importaciones o cambios importantes, entrá a Copias de seguridad y descargá un respaldo JSON.

La aplicación utiliza IndexedDB local. La importación de un respaldo reemplaza los datos existentes por los incluidos en ese archivo.
